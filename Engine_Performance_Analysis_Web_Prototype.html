Calculation method used

Brake Power (kW)BP = (2 × π × N × T) / 60000
Fuel Energy Input (kW)Fuel rate × Calorific value / 3.6
BSFC (kg/kWh)Fuel consumption / Brake power
Brake Thermal Efficiency (%)(Brake power / Fuel energy input) × 100
Air-Fuel RatioAir mass flow rate / Fuel mass flow rate

Equations follow the project report. Calculations run in this browser prototype; it is not connected to a physical engine or live sensors.
